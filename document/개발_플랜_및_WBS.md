# Azure 기반 물류센터 프로젝트 개발 플랜 및 WBS

## 1. 전체 개발 단계(WBS)

### 1단계: 데이터 제너레이터(시뮬레이터) 개발
- 개발 환경 준비 (Python, Docker, .env)
- 환경변수 설계 및 샘플 .env 작성
- 데이터 제너레이터 코드 구현 (MQTT/HTTP 지원)
- 도커라이즈 및 테스트

### 2단계: IoT Hub 등 Azure 리소스 준비
- IoT Hub, Stream Analytics, DB 등 리소스 생성
- 네트워크/보안/인증 설정
- 리소스 연결 정보 .env에 반영

### 3단계: 데이터 수집/저장/분석 파이프라인 구현
- IoT Hub → ASA → DB 연동 테스트
- 데이터베이스 테이블/뷰 생성
- 데이터 흐름 검증

### 4단계: 웹 대시보드/시각화 개발
- 프론트엔드/백엔드 개발 환경 준비
- API 설계 및 연동
- 실시간/집계 데이터 시각화 구현

### 5단계: 운영/배포/테스트
- 도커/CI/CD 파이프라인 구축
- 모니터링/로깅/알림 설정
- 운영 매뉴얼/테스트 시나리오 작성

---

## 2. 우선순위 및 요청 사항
- 1단계(데이터 제너레이터)부터 단계별로 진행
- 각 단계별로 필요한 리소스, 환경변수, 샘플 코드, 도커 설정 등 요청/안내 예정
- .env 파일로 환경변수 일원화, 도커 환경 적극 활용
