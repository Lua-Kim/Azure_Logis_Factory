# Azure 기반 물류센터 컨베이어 벨트 레일 시스템 데이터 분석 설계서

## 1. 프로젝트 개요
- 여러 물류센터의 컨베이어 벨트 레일 시스템 데이터를 Azure 기반으로 수집, 저장, 분석, 시각화
- IoT Hub, Azure Stream Analytics(ASA), Azure PostgreSQL, Azure MS SQL, Fabric, 웹 대시보드 활용
- 본사 집계 및 각 센터의 경영상 손실 최소화, 성과 관리, 병목 현상 분석, KPI 관리 목적

## 2. 시스템 아키텍처
- 센서(바스켓, 병목, 컨테이너 등) → IoT Hub → ASA(실시간 분석) → Azure PostgreSQL/MS SQL(저장) → Fabric(집계/분석) → 웹 시각화
- 본사는 각 센터의 집계 데이터와 실시간 현황을 통합 관리

## 3. 데이터베이스 설계
### 주요 테이블
- 센터(Center): 센터 정보, 구조, 설정 등
- 라인(Line): 센터 내 라인 정보
- 구간(Section): 라인 내 구간 정보
- 센서(Sensor): 구간별 센서 정보(종류, 위치 등)
- 바스켓(Basket): 작업물 이동 및 상태 기록
- 컨테이너(Container): 컨테이너 정보 및 이동 기록
- 차량(Vehicle): 입출고 차량 정보
- 병목 이벤트(BottleneckEvent): 발생 시각, 라인/구간, 지속 시간, 원인, 영향 바스켓/컨테이너 등
- KPI(KPI): 일별/월별 누적 처리량, 평균 대기 시간, 병목 발생 빈도, 손실 추정액 등
- 손실 분석(LossAnalysis): 병목으로 인한 대기 시간, 해당 시간의 처리량 손실, 금액 환산 등
- 프리셋/설정(Preset/Config): 센터별 커스텀 설정, 프리셋 관리
- 집계(Aggregation): 본사 집계용, 센터별/라인별/구간별 주요 지표

## 4. 데이터 흐름 및 분석
- IoT Hub → ASA → PostgreSQL/MS SQL: 실시간 센서/병목/바스켓 데이터 저장
- ASA: 실시간 병목 감지, 대기 시간 계산, KPI 산출, 손실 추정
- Fabric: 집계 데이터 분석, 트렌드, 예측, 본사 대시보드 제공

## 5. 웹 시각화
- 센터/라인/구간별 실시간 현황(그래프, 표, 리스트)
- 병목 발생 구간 히트맵, 대기 시간/손실액 시계열 그래프
- KPI 대시보드(누적 처리량, 평균 대기 시간, 병목 빈도, 손실액 등)
- 커스텀/프리셋 설정 UI, 집계 데이터 비교/분석 기능

## 6. 분석 및 관리 기능
- 병목 현상 발생 구간/라인별 통계, 빈도, 영향 분석
- 대기 시간 및 손실액 자동 산출 및 알림
- 일별/월별/센터별 KPI 관리 및 트렌드 분석
- 본사/센터별 성과 비교, 손실 최소화 전략 수립 지원

## 7. 추가 설계 포인트
- 센터/라인/구간/센서 구조의 유연성(센터별 구조 다름)
- 데이터 품질 관리(센서 오류, 데이터 누락 등)
- 권한/역할 기반 접근 제어(본사/센터 관리자)
- 확장성(센터/라인/센서 추가 용이)
- 장애/이상 이벤트 실시간 알림

## 8. 개발 및 운영
